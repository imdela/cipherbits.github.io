Confidentialité

Confidentialité

Cipherbits est un outil gratuit qui fonctionne entièrement dans votre navigateur. Rien à créer, rien à installer, rien à suivre.

Ce que nous stockons

Rien. Nous n’avons ni comptes, ni base de données d’utilisateurs, ni serveur qui reçoit vos mots de passe. Chaque mot de passe est généré sur votre appareil, dans l’onglet que vous avez ouvert.

Ce que nous collectons

Pas de cookies, pas de traqueurs, pas de scripts tiers, pas de balises d’analyse. Le site est une page statique servie en HTTPS — les seules requêtes que votre navigateur émet sont pour la page elle-même, ses styles et ses ressources.

Génération locale

Votre mot de passe ne quitte jamais votre appareil. Le générateur lit le hasard dans la source cryptographique de votre navigateur (crypto.getRandomValues), construit le mot de passe en mémoire et l’oublie dès que vous fermez l’onglet. Nous ne pouvons ni le voir, ni le récupérer, ni le stocker — parce qu’il ne nous parvient jamais.

Requêtes réseau

Générer un mot de passe ne déclenche aucune requête réseau. Rien n’est envoyé quand vous cliquez sur Générer, Copier ou Télécharger. Le code qui s’exécute dans votre navigateur est le même code publié dans le dépôt source.

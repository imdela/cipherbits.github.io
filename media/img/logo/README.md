# Cipherbits — logo files

## Variants

| File | What it is | Use it on |
|---|---|---|
| `favicon-cipherbits.png` | The C mark, green on a transparent background | Source for the favicon set and the logo mark |
| `logo-cipherbits.png` | Full logotype, dark wordmark + green accents, transparent background | Light surfaces (light theme) |
| `logo-cipherbits-dark-bg.png` | Full logotype, white wordmark + green accents, transparent background | Dark surfaces (dark theme, header/footer on dark) |
| `web/favicon.ico/` | The favicon set, all sizes and formats | Browser tab, home screen |
| `../../sources/PSD/logo-cipherbits.psd` | Editable source of the logotype (Photoshop) | Any rework of the logotype |
| `../../sources/PSD/favicon-cipherbits.psd` | Editable source of the C mark and favicon (Photoshop) | Any rework of the favicon set |

## Theme pairing

The site has a dark and a light theme. Each surface shows the matching
variant:

- Dark theme → `logo-cipherbits-dark-bg.png`
- Light theme → `logo-cipherbits.png`

Both variants share the same drawing and proportions, so the switch is a
simple swap with no layout shift.

## Archive

The previous logo generation (old logotype, letter-C marks and PSD sources)
is kept under `media/archives/` for reference. The site does not use it.
